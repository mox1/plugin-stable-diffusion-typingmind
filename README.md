# Stable Diffusion Image Editing Plugin

Edit and transform your images with the Stable Diffusion Image Editing Plugin powered by Stability AI.

**API Key Required:** You'll need a valid Stability AI API key. Obtain one from their website: https://platform.stability.ai/account/keys

## Features

This plugin supports 4 editing modes:

### 1. Erase
Remove unwanted objects from your images. Simply attach an image and ask to remove something.

### 2. Search and Replace
Find objects in your image and replace them with something else. The AI automatically segments the object you want to replace.

### 3. Search and Recolor
Change the color of specific objects in your image. The AI automatically identifies and recolors the object you specify.

### 4. Remove Background
Accurately remove the background from an image, keeping only the foreground subject.

## Examples

- "Remove the background from this image"
- "Replace the car in this photo with a motorcycle"
- "Change the color of the shirt to blue"
- "Erase the person in the background"
- "Make the sky purple in this image"
- "Replace the cat with a dog"

## How to Use

1. Attach an image to your message
2. Describe what you want to do with the image
3. The AI will automatically choose the appropriate editing mode and process your request

## Settings

- **StabilityAI API Key** (required): Your API key from Stability AI
- **Output Format** (optional): Choose between jpeg, png, or webp (default: png)
